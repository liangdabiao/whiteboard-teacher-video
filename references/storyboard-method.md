# 分镜方法论

> 分镜是杠杆最大的那一层。分镜错了，画面画得再漂亮也只是一份幻灯片。

## 写分镜前先回答三个问题

1. **观众看完要能复述的一句话是什么？** 写不出来就是选题没定，别开工。
2. **他们现在的错误认知是什么？** 新内容要修正它，而不是叠加。
3. **能用一个贯穿全片的物体/意象吗？**（雪球、天平、存钱罐、树、火车、时钟）

## 全片结构：五段式

| 段 | 时长占比 | 目标 |
|---|---|---|
| **Hook** | 前 5–10 秒 | 一个反直觉的事实或一个真问题 |
| **直觉** | 15% | 让观众"哦原来是这样"的类比或演示 |
| **机制** | 40% | 真正的因果链，一步一步 |
| **例子与数字** | 25% | 具体算一遍，带真实数字 |
| **收束** | 10% | 回到开场那个问题，给出答案 |

**反例**：上来就讲定义 → 读者第 3 秒就划走。
**正例**："为什么你永远存不下钱？" → 复利的存在 → 机制 → 算一笔 30 年的账 → 回到开头。

## 一页一观点

- **一页 = 一个观点**，不是一页讲三个并列点（并列点请拆成三页，或做成一页的三个 beat）
- 每页 2–3 句口播，**2–4 秒必须出现新东西**
- 页与页之间要有推进（因为 A 所以 B），不能是并列清单

## 分镜 JSON 结构

```json
{
  "title": "相对论入门：为什么时间会变慢",
  "summary": "一句话说清这条片子讲什么",
  "durationSec": 90,
  "style": "whiteboard",
  "cast": "none",
  "pages": [
    {
      "id": "p01",
      "section": "开场：一个老问题",
      "say": "本页口播全文（2-3 句）",
      "beats": [
        { "at": "c0", "object": "一列火车", "action": "从左向右驶过站台",
          "camera": "固定", "text": "1000 km/h" },
        { "at": "c1", "object": "站台上的观察者", "action": "举起望远镜测量",
          "camera": "推近", "text": "" }
      ]
    }
  ]
}
```

- `at`：落点。`c0` = 第 0 句开始，`c2` = 第 2 句开始，`c2:三十` = **念到"三十"这个词**（关键数字用它）
- `object`：**具体的东西**。禁止「标题」「要点」「卡片」「背景」这类布局词
- `action`：**真实的动作**。禁止「出现」「显示」「淡入」「逐条列出」这类空词
- `text`：该 beat 出现的字，**≤ 8 个中文字**

## 分镜 lint（引擎会自动跑，自己也要自查）

| 规则 | 级别 |
|---|---|
| `object` 必须是具体物，不是布局词 | 红 |
| `action` 必须是真动作，不是「出现/显示」 | 红 |
| 每条上屏文字 ≤ 8 字 | 红 |
| 首尾页不能是纯文字页；结尾落在"物体做了个动作"，不是居中金句卡 | 红 |
| 纯文字 beat 占比 ≤ 30% | 红 |
| 上屏数字必须能在资料或口播里找到（"六成" = 60%） | 红 |
| 每 ≤ 6 秒至少一个 beat | 黄 |
| 连续三个 beat 相同运镜 | 黄 |
| 没有插画素材时**不画脸**，只画手/背影/剪影，或让物体当主角 | 红 |

## ★ 必须让用户确认

分镜写完，**停下来念给用户听**，逐页说：这页讲什么、画什么。用户改了就改，改完再开工。

理由：分镜阶段改一句话是秒级的事，画完再改就是重画。

## 口播写作

- **讲正确的用法，不纠缠原文的错**（如果你在改编别人的文章）
- **举例 ≠ 比喻**：例子用真材料（真数值、真编码、真实验）；比喻只用来建立直觉，且要明说"这是比喻"
- 受众是成年人：直接讲机制和参数，不要铺垫"众所周知"
- 单句 ≤ 40 字（长了配音会喘，且画面难跟上）
- 句尾带标点：`。？！` 决定停顿 0.4s，`，、；` 决定 0.18s
- 每讲一个概念，留一个"为什么这样设计"的启发点

## 时长估算

- 中文语速约 4.3 字/秒（`runtime/timing.js` 的 CPS）
- 90 秒片子 ≈ 380–400 字口播
- 每页 2–3 句 ≈ 10–15 秒
- 所以 90 秒 ≈ 7–9 页

## 画面的"贯穿物体"

选定一个比喻物体，让它贯穿全片：

| 主题 | 可用物体 |
|---|---|
| 复利/存钱 | 雪球、存钱罐、硬币堆 |
| 相对论 | **火车、站台、光束、时钟** |
| 生长/习惯 | 树苗、藤蔓 |
| 决策 | 天平、岔路口 |
| 神经网络 | 点阵、信号 |

好处：观众有连贯的视觉锚点，页面之间不是割裂的。也符合「一页一观点」——物体在动，观点在推进。
