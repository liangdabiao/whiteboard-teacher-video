# 五套风格包

风格在 `script.js` 的 `META.style` 指定。**换风格只需改这一个词**，页面代码不动。

## 怎么选

| 你要做的东西 | 选 | 为什么 |
|---|---|---|
| 数学推导、逐步演算、流程 | `whiteboard` | 手绘感强、留白多、写字清楚 |
| 科学科普、课堂感、类比演示 | `chalkboard` | 板书天然适合"边写边讲" |
| 通用讲解、不确定 | `study`（默认） | 中性、安静、不出错 |
| 商业/心理/成长类、比喻叙事 | `warm-story` | 暖色扁平插画、情绪友好 |
| 软件、工程、架构、终端 | `tech-dark` | 深色、等宽字体、青色强调 |

---

## study（默认 · 安静书卷）

暖纸底、墨色手绘、默认调色板。**拿不准就用它。**

- 手绘感：中等（运行时默认参数）
- 背景：暖纸 + 细点阵
- 适合：任何题材的安全选择

---

## whiteboard（白板马克笔 · RSA Animate 风）

**这是最有"讲解感"的风格**，白色板面、黑色马克笔主线、彩笔只用于强调。

语法卡要点：
- **黑笔是主角**：结构、轮廓、文字都是 `ink`；红/蓝/绿/橙只用于圈注、标签、勾、强调
- **一屏最多两支彩笔**
- **一切都是画出来的**：形状 `dur` 0.5–1.0s 逐笔描，文字 `cps` 10–14 逐字写。**不用淡入/弹跳/飞入**
- **笔跟嘴走**：用 `P.cw` 让东西在念到它的那一刻出现，画得比说话稍快，留半拍给观众看
- **强调靠笔法**：圈 `ring`、下划 `underline`、叉 `cross`、勾 `check`、荧光笔 `mark`
- **画面从左上往右下生长**（跟真人写字同序），画满了就翻页或移镜到空白区
- 前 3 秒落下第一笔
- 每屏中文字 ≤ 8 字，正文 ≥ 36px

**禁止**：大色块、渐变、阴影、发光、蓝紫色调、照片质感、3D。

---

## chalkboard（深绿板岩 · 粉笔）

粉笔颗粒滤镜（每笔都打洞）、粉笔色。特别适合"公式推导"和"课堂讲解"。

- `ink` 是**粉笔白**，`paper` 是**板岩深绿**（反色主题）
- `*F` 浅填充自动变成**深色**（深板上浅填充会像灯一样发光，所以引擎把填充都压到接近板色）
- 粉笔色：`red` 粉红、`orange` 桃、`green` 浅绿、`blue` 天蓝、`yellow` 粉黄
- 适合：公式、推导、课堂板书感
- **禁止**：和 whiteboard 混用纸纹；粉笔色不要当线色大面积用

---

## warm-story（暖色扁平插画 · 比喻叙事）

几乎不抖的线条、柔和形状、暖调。像绘本。像"理财 101"那种。

- 手绘感：**最低**（`roughScale: 0.32`，单描边）
- 有一个**贯穿全片的比喻物体**（雪球、天平、硬币堆、树）
- 数字落在**物体上**，不是单独的文字卡
- 调色板：赭红=代价/风险、芥末黄=钱/重点/答案、鼠尾草绿=成长/好路径、深青=时间/长线、藕粉代替紫
- **禁止**：铅笔素描感、密集数字、技术细节堆砌

---

## tech-dark（石墨深色 · 青色强调）

像画电路图，不像画草稿。线条几乎不抖、细、单描边。

- `ink` 是暖白，`paper` 是抬高一级的面板色
- **青色 `blue` 是唯一强调色**：路径、选中、答案
- 琥珀 `orange`=警告/成本，红=错误，绿=通过
- 48px 极淡网格底
- 适合：软件架构、系统设计、终端、代码
- **禁止**：发光、渐变天空、霓虹

---

## 配色键名（所有风格统一）

**页面代码只写语义名，风格包负责解析成色值。所以换风格颜色自动跟着变。**

```
ink soft muted faint          ← 墨色四档，由深到浅
blue orange red green purple yellow
blueF orangeF redF greenF …   ← F = 该色向纸色的浅填充
paper                         ← 纸/板底色
inkF softF mutedF faintF      ← 墨色四档的浅填充
```

深色主题（chalkboard/tech-dark）里 `*F` 自动变暗。所以：

```js
P.box(x, y, w, h, { fill: 'blueF', color: 'blue' })   // 浅色主题=浅蓝，深色主题=深青
```

**不许硬编码 hex。** 写了风格包没有的颜色名，质检会报出来（不会静默变黑）。

## 单片微调（不换风格的局部覆盖）

不想为了一个元素换整片风格，可以只给一页写 `META.look` 覆盖配色/字体。详见 `engine/runtime/look.js`（27 行）。
